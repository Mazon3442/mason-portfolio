01

Infrastructure

Self-hosted homelab

A Linux and Docker Compose platform I designed and operate. It hosts media streaming (Jellyfin), photo backup (Immich), password management (Vaultwarden), personal finance (Firefly III), game servers, databases, and monitoring.

Public services run behind Nginx Proxy Manager with Cloudflare DNS and Let's Encrypt certificates for HTTPS remote access. I wrote recovery procedures for network changes, service migrations, stale IP dependencies, and backup and rollback.

Linux · Docker Compose · Nginx · Cloudflare DNS · TLS

02

Hardware

MasonDeck control console

A Raspberry Pi 5 touchscreen kiosk that works as a physical control panel for the homelab. Its web dashboard runs on an SSH-backed API that shows service health and storage and runs server controls remotely.

The Pi also serves network-wide DNS through Pi-hole and is reachable over HTTPS through the homelab's reverse proxy. When the network was migrated, I updated service targets, rebuilt containers, and verified connectivity end to end.

Raspberry Pi 5 · SSH · Pi-hole · Docker

03

Performance

GPU-accelerated media transcoding

A hybrid GPU/CPU transcoding pipeline built on Tdarr, FFmpeg, and an AMD Radeon RX 6600 through VAAPI. Benchmarking hardware HEVC against H.264 showed a severe HEVC bottleneck on this card, so I redesigned the pipeline around speed instead of forcing HEVC.

Codec, bitrate, and file-state rules skip media that's already efficient, and every output keeps its filename, metadata, subtitles, and audio tracks.

FFmpeg · VAAPI · Tdarr · Docker · Benchmarking

04

Automation

Automation assistant

Configured and extended OpenClaw, a self-hosted AI automation platform, to run scheduled health checks across the homelab and handle diagnostics and limited remote administration through Telegram.

Its runbooks and project notes live in a Markdown knowledge base in Obsidian, with backups.

OpenClaw · Telegram · Obsidian · Automation
